Reuse the glossary

The glossary is published under a CC BY 4.0 licence, and software can read it as well as people. The audioBlast Vocabulary Server has the same kind of API, linked data and MCP server.

JSON API

Search terms by name or acronym, or fetch a term’s definition and references by its URI or short name.

API documentation

Linked data

Download the whole glossary as a SKOS concept scheme, or request any term as RDF from its own URI.

JSON-LD Turtle

MCP server

Let AI assistants such as Claude search the glossary and read its definitions and references.

Add it to Claude Code 
claude mcp add --transport http abg https://glossary.acousti.cloud/api/mcp
