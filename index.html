Open data

Reuse the data

The glossary is published under a CC BY 4.0 licence, and software can read it as well as people. The audioBlast API and Vocabulary Server offer the same kinds of access.

JSON APIs

Query audioBlast’s recordings, taxa and traits, or search the glossary and vocabularies for a term by name or acronym and fetch its definition and references by its URI.

audioBlast API Glossary API Vocabulary API

Linked data

Download the whole glossary as a SKOS concept scheme, or request any term as RDF from its own URI.

JSON-LD Turtle

MCP servers

Let AI assistants such as Claude search recordings, taxa and traits, and read the definitions of terms and their references, through the Model Context Protocol. Each server is read-only.

  • audioBlast API: the recordings, taxa, traits, references, specimens and locations
  • Vocabulary Server: the terms for calls, sound production and recording methods
  • Glossary: the terms of bioacoustics and ecoacoustics
Add them to Claude Code 
claude mcp add --transport http audioblast https://api.audioblast.org/mcp
claude mcp add --transport http audioblast-vocab https://vocab.audioblast.org/api/mcp
claude mcp add --transport http glossary https://glossary.acousti.cloud/api/mcp
